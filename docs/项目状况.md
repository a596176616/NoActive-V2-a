## 4. 与 Cirno 仓库对比结论（2026-07-21）

对比对象：[Adkimsm/Cirno](https://github.com/Adkimsm/Cirno)（镜像自 Nep-Timeline/Cirno，已 clone 到 `/tmp/Cirno`）。

### 4.1 关系定位
- Cirno 与本地仓库属于**同赛道（应用冻结）不同演进**。
- Cirno README 明确致谢参考了 `myflavor/NoActive-V2`（即本仓库上游）、`Anatdx/Nemuri`、`MoWei-2077/FrozenVS`、`XingC123/BackgroundOpt`、`Freezer-Team/Cirno`。

### 4.2 主要差异

| 维度 | 本地 NoActive-V2-a | Cirno |
|---|---|---|
| 平台 | Android 10+（minSdk 29） | Android 12+（minSdk 31），仅 cgroup v2 |
| 包名 | `cn.myflv.noactive` | `nep.timeline.cirno` |
| Gradle DSL | Groovy | Kotlin DSL + `libs.versions.toml` |
| AGP / Kotlin | 8.10.0 / 2.1.21 | 9.2.0 / 2.3.20 |
| compileSdk / target | 36 / 36 | 37 / 37 |
| Java | 11 | 25 |
| 子模块 | `:app`, `:blockmiui` | `:app`, `:librekernel`（ReKernel netlink） |
| UI | 传统 View + blockmiui | Jetpack Compose + miuix-kmp + material3 + haze |
| staticScope | false | **true** |
| Hot Reload | 不支持 | **支持**（`onHotReloading/onHotReloaded` 完整状态保存/恢复） |
| 系统侧 Hook 入口 | `AndroidHook.hook()`（AbstractAppHook） | `AndroidHooks.start(classLoader)`（静态） |
| Hook 覆盖面 | 14 个（含 MIUI PowerKeeper/Greeze/Binder 专属） | 30+ 个（Audio/Camera/Autofill/Credential/InputMethod/Location/PendingIntent/Notification/Recorder/VPN/WakeLock/OomAdj/Compaction/Signal + FreezeHookManager 多后端 Millet/Hans/ReKernel/NkBinder + NetworkSpeedMonitor） |
| 冻结执行 | `FreezerService` AIDL（`action.FREEZE`）→ `BaseFreezeUtils` V1/V2 by pid+uid | `CirnoBinderProvider`（ContentProvider authorities=`nep.timeline.cirno.binder`）→ `ICirnoService`（含 getSignal/getStatusSnapshot/getRunningApplication/getNetworkSpeed/isFrozen/getFrozenStates/getMonitorSnapshot） |
| 内核事件 | 无 | `librekernel` netlink 监听 |
| scope.list | `system`, `com.miui.powerkeeper`, `cn.myflv.noactive` | `system`, `com.android.systemui` |
| 配置管理 | `FreezerConfig` + `ConfigFileObserver` + `ConfigUtils` | `ConfigManager` + `ConfigManagerJson` + policy（Capability/FreezeExemption/PolicyKey） + ApplicationSettings/GlobalSettings/AppConfigs |
| AI 协作 | 无 `AGENTS.md` | 有 `AGENTS.md`（提交规范、构建命令、规则） |
| License | README 简述 | GPL-v3 完整文本 |
| 提交风格 | 中文 `fix(broadcast): ... (F3A-029)` | 英文 `<action>(<scope>): <summary>`，GPG 签名 |

### 4.3 本地仓库的差异化优势
- 兼容 Android 10（minSdk 29），Cirno 仅 Android 12+
- MIUI 专属 Hook（PowerKeeper / Greeze / BinderTrans / BinderState），Cirno 未覆盖
- 简单 V1/V2 AIDL 冻结接口，依赖少

### 4.4 可考虑从 Cirno 借鉴的点（暂不实施，仅记录）
- `staticScope=true` + `autoHotReload=true`（性能与开发体验）
- Hot Reload 状态保存/恢复机制
- 多冻结后端 FreezeHookManager（Millet/Hans/ReKernel/NkBinder）
- `librekernel` netlink 内核事件监听
- Hook 覆盖扩展（Audio/Camera/InputMethod/Autofill/Credential/Location/VPN/WakeLock 等）
- Compose UI 现代化（成本较高，需评估）
- Kotlin DSL + version catalog + AGP 9.x + Java 25 工具链升级
- `AGENTS.md` AI 协作规范
- ContentProvider 暴露 Binder（替代 Service intent-filter）
